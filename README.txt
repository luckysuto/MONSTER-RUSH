MONSTER RUSH - Browser Edition

ファイル
- index.html : 画面構造
- style.css  : デザイン・スマホ対応
- game.js    : ゲーム処理
- monsters.js: モンスター20体・分岐進化データ

遊び方
1. 4ファイルを同じフォルダに置く
2. GitHubリポジトリへ4ファイルをアップロード
3. Settings > Pages で main ブランチ / root を公開設定
4. 公開URLをSafari/Chromeで開く

注意
- ES Modulesを使うため、file:// で直接開くのではなくGitHub Pages等のHTTPサーバーで開いてください。
- セーブはブラウザのlocalStorageに保存されます。同じ端末・同じブラウザで利用してください。
- ブラウザのデータ消去やプライベートブラウズではセーブが消える場合があります。
- 進化はレベル10以上・魔石10個が必要です。一度進化すると戻せません。
- 現在の版はブラウザで遊べる基本版です。オンライン対戦、クラウド同期、全60形態の専用3Dモデル・個別アニメーション、完全なストーリー/ダンジョンは未実装です。
- 実機での操作・性能検証は利用者の端末で最終確認が必要です。

基本操作
- バトル：攻撃 / 回避 / スキル / 必殺技
- PC：JまたはEnter=攻撃、Space=回避、K=スキル、L=必殺技、Esc=一時停止
- 育成：訓練で経験値を獲得
- 探索：地域を選ぶと報酬と仲間発見チャンス
- 仲間：モンスターを選択して操作個体を変更、進化分岐を選択
